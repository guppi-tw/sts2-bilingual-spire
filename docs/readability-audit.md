# 併記時の読みやすさ

2026-11-15、ゲームv0.113.0・macOS Apple Siliconで英日併記を調査しました。
数値はゲーム内のフォントサイズです。実際の画面上の大きさは解像度や表示倍率でも変わります。

| 場所 | 実測 | 対応・対策案 |
| --- | --- | --- |
| レリック名 | 修正後は長い名前も22 | v0.5.3で横並びに変更。文字を縮める処理から外し、ツールチップの枠が名前に合わせて広がるようにした |
| 効果説明の見出し | 修正後は22以上 | 同じツールチップ内の見出しも横並びに変更 |
| カード本文 | 「アセンダーの災厄」「堕落」で21→14、訳文は12 | カード内の併記を残し、ホバー時にカードの脇へ読みやすい大きさの全文対訳を出す方法を推奨 |
| カード名 | 確認した6枚では26→17 | 横幅が狭いため、一律の横並びは長い名前をさらに縮める恐れがある。カード名と本文を同じ補助表示で読めるようにする |
| プロフィール欄 | 見出し24→7、説明18→7 | ボタンの幅と高さを確保し、説明の折り返しを許す。クリック範囲も同じ大きさにする |
| メインメニューの項目 | 32→15 | 横に余白があるため、横並びとボタン幅の調整が候補 |
| MOD適用中の表示 | 16→8 | 固定の高さに押し込めず、折り返した分だけ表示枠を高くする |
| イベントの見出し | 36→20 | 本文より優先度は低め。横並びが入る幅か確認し、長い名前は折り返す |

v0.5.3で実装したのはレリック名とツールチップ見出しの改善です。表のそれ以外は、調査結果をもとにした未実装の案です。

優先順位は、プロフィール欄とメニューの極端な縮小、長いカード本文、イベントの見出しの順が妥当と考えます。
一律に最低文字サイズだけを上げると、文章の欠けや隣の項目との重なりが起きます。表示枠を広げられる場所と、カードのように面積が決まっている場所を分けて対処します。

調査対象は実際のメインメニュー、6種類のカード、4種類のイベント、レリックの報酬・ツールチップ、マップです。
テスト用に作った単独のLabelは上の集計から除外しました。全カード・全言語ペア・ショップなどの全画面を調べたものではありません。

Debugテストのログに `READABILITY AUDIT` として単独表示と併記時のサイズを記録します。
レリック名は通常の名前と長い名前、英日・仏韓、単独表示への復帰を検査しています。

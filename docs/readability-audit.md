# 併記時の読みやすさ

2026-11-15、ゲームv0.113.0・macOS Apple Siliconで英日併記を調査しました。
数値はゲーム内のフォントサイズです。実際の画面上の大きさは解像度や表示倍率でも変わります。

| 場所 | 実測 | 対応・対策案 |
| --- | --- | --- |
| レリック名 | 修正後は長い名前も22 | v0.5.3で横並びに変更。文字を縮める処理から外し、ツールチップの枠が名前に合わせて広がるようにした |
| 効果説明の見出し | 修正後は22以上 | 同じツールチップ内の見出しも横並びに変更 |
| カード本文 | カード内は21→14、訳文12。ホバー時の対訳は主言語26・訳文22 | v0.5.4で大きな全文対訳を追加。カード内の併記と標準のキーワード説明は残す。長文はカード上のホイールでスクロール |
| カード名 | カード内は26→17。ホバー時は26 | v0.5.4で大きな対訳の上にカード名を横並びで表示。長い名前は折り返す |
| プロフィール欄 | 修正前は見出し24→7、説明18→7。修正後は24・18を維持 | v0.5.4で幅と折り返しを確保し、クリック範囲も本文に合わせて拡大。アイコンの縦横比は維持 |
| メインメニューの項目 | 修正前は32→15、修正後は32 | v0.5.4で横並びに変更し、文字に合わせてボタンの幅・高さを調整 |
| MOD適用中の表示 | 16→8 | 固定の高さに押し込めず、折り返した分だけ表示枠を高くする |
| イベントの見出し | 36→20 | 本文より優先度は低め。横並びが入る幅か確認し、長い名前は折り返す |

v0.5.3でレリック名とツールチップ見出しを、v0.5.4でカードの拡大対訳・プロフィール欄・メインメニューを改善しました。
MOD適用中の表示とイベント見出しは未対応です。

v0.5.4では実ゲームで、メニューの収録16言語との併記、元の文字サイズ、クリック範囲、単独表示への復元を検証しました。
カードはマウスによる表示・解除、画面左右での収まり、英日・仏韓、ホバー中の表示モード変更、アップグレード時の数値、ロック中の非表示を確認しました。
非常に長い文章のテスト用データを使い、カード上のホイールで対訳をスクロールできることも検証しています。

調査対象は実際のメインメニュー、6種類のカード、4種類のイベント、レリックの報酬・ツールチップ、マップです。
テスト用に作った単独のLabelは上の集計から除外しました。全カード・全言語ペア・ショップなどの全画面を調べたものではありません。

Debugテストのログに `READABILITY AUDIT` として単独表示と併記時のサイズを記録します。
レリック名は通常の名前と長い名前、英日・仏韓、単独表示への復帰を検査しています。

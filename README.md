# Bilingual Spire

SteamのMac版 **Slay the Spire 2** で、2つの言語を切り替えたり併記したりできる語学学習用MOD。
初期状態は学習する言語で表示し、Zを押している間だけ母国語を確認できます。
ゲーム収録の公式翻訳を利用し、外部の翻訳APIは使いません。

v0.5.7 / 動作確認済み: public-beta のゲームv0.113.0 / macOS Apple Silicon

## Steamワークショップから導入

[Bilingual Spireをサブスクライブ](https://steamcommunity.com/sharedfiles/filedetails/?id=3840138909)

1. Steamのゲームの「プロパティ → ゲームのバージョンとベータ」で `public-beta` を選びます。通常ブランチ・Windows・Linuxは未検証です。
2. 上のWorkshopページでサブスクライブし、Steamのダウンロード完了を待ちます。
3. ゲームを起動し、「設定 → MOD設定」でBilingual Spireを有効にします。再起動を求められた場合は再起動してください。
4. Zを押している間だけ翻訳、Cで表示モード切り替え、Gで言語設定を使えます。

ZIP版から移る場合は、ゲームを終了して手動配置した `mods/BilingualSpire` フォルダを `mods` の外へ移してください。同じバージョンの手動配置版が残ると、ゲームはそちらを優先します。言語設定やMOD用の進行データは引き継がれます。

更新はSteamが配信します。MOD有効時の進行は通常プレイと別に保存されます。このMODはセーブの移行や削除を行いません。

## ZIPから導入

[BilingualSpire-v0.5.7-macOS.zip をダウンロード](https://github.com/guppi-tw/sts2-bilingual-spire/releases/download/v0.5.7/BilingualSpire-v0.5.7-macOS.zip)
（[リリース一覧](https://github.com/guppi-tw/sts2-bilingual-spire/releases)）

SteamのMac版Slay the Spire 2がインストールされていれば使えます。
ビルド、.NET SDK、BaseLibの追加インストールは不要です。動作確認はゲームv0.113.0・Apple Siliconで行っています。

1. ゲームを終了し、上のZIPをダウンロードして展開します。GitHubが自動で付ける `Source code (zip)` は導入用ではありません。
2. SteamライブラリでSlay the Spire 2を右クリックし、「管理 → ローカルファイルを閲覧」を開きます。
3. Finderで `SlayTheSpire2.app` を右クリックして「パッケージの内容を表示」を選び、`Contents → MacOS` を開きます。
4. その中に `mods` フォルダを作ります。すでにある場合はそのフォルダを使います。
5. ZIPから出てきた `BilingualSpire` フォルダを、丸ごと `mods` の中に入れます。配置後の構成は次のとおりです。

```text
SlayTheSpire2.app/
  Contents/
    MacOS/
      mods/
        BilingualSpire/
          BilingualSpire.dll
          BilingualSpire.json
```

6. Steamからゲームを起動し、「設定 → MOD設定」で「Bilingual Spire」を有効にします。再起動を求められた場合は再起動してください。
7. Cで表示モード、Gで言語の組み合わせを変更できます。Zを押している間だけ言語2を表示します。

MOD有効時の進行状況は通常プレイと別に保存されます。初めてMODを使う場合は、
`~/Library/Application Support/SlayTheSpire2/` をバックアップしてから起動してください。
通常プレイの進行が表示されなくても、元のセーブが消えたわけではありません。このMODは進行データの移行を行いません。

更新時はゲームを終了し、`mods/BilingualSpire` を新しいZIP内の同名フォルダに置き換えます。
言語や表示モードの設定は別の場所に保存されているため引き継がれます。
無効にする場合はMOD設定でオフにして再起動します。アンインストールする場合はゲーム終了後に `mods/BilingualSpire` を取り除きます。

v0.5.1では、ネオーのレリック取得後に「進む」ボタンが画面外へ消える不具合を修正しました。
以前のバージョンで止まった場合は、更新後にゲームを起動し、保存済みのランを続けてください。

## 使い方

| 操作 | 動作 |
| --- | --- |
| Zを押している間 | 言語2（母国語）のみ表示。離すと直前の表示に戻る |
| C | 言語1のみ → 言語2のみ → 両方表示 → 言語1のみ… |
| G | 右上の言語選択欄を開く・閉じる |
| 設定欄の「今すぐ切り替え」 | マウスで表示モードを切り替える |

Z・C・Gは本体の標準キー割り当て（マウス併用・キーボードのみ）と重ならないキーです。fnキーは不要です。
v0.5.7から、旧F7・F8・F9をそれぞれZ・C・Gへ変更しました。
初期の組み合わせは英語・日本語です。Gからゲーム収録の16言語を選べます。
表示モードと言語の組み合わせは自動保存され、次回起動時に復元されます。

初回から言語1（初期設定は英語）で表示します。分からないときだけZを押して翻訳を確認できます。Gで「言語2」に母国語を選んでください（初期設定は日本語）。
Zを離すと、押す前の単言語・併記モードに戻ります。この一時表示は保存されず、押したまま終了しても次回は元のモードで起動します。
文字入力中やCommand・Control・Option・Shiftとの同時押しはショートカットを無視し、ゲームから別アプリへ移った場合も一時表示を解除します。Zを押したままC/Gや言語設定を操作した場合は、その明示的な変更を優先します。

- カード、メニュー、レリック、イベント、ツールチップなどの翻訳文を更新します。
- 併記中にカードへマウスを合わせると、カード内の併記に加えて、大きなカード名と全文対訳を横に表示します。主言語は26、訳文は22の文字サイズで、ゲーム標準のツールチップ背景を使います。長文はカード上でホイールを回すとスクロールできます。
- メインメニューは横並びにして元の文字サイズを保ちます。プロフィール欄は折り返しに合わせて広げ、クリック範囲も文字全体を覆うようにします。単独表示に戻すと元の配置に戻ります。
- レリック名とツールチップの見出しは「言語1 / 言語2」の横並びにし、文字が小さくなりすぎないようにしています。
- その他の併記では言語1を上、言語2を下に表示します。空行で分かれた文章は、原文の各段落のすぐ下に対応する翻訳を置きます。
- 段落内の改行や文字色を保ちます。段落数が違う場合や表などを安全に分割できない場合は、全文の下に翻訳を表示します。
- 凡例とカード・イベントの本文は、言語2を言語1の約85%の文字サイズで表示します。本文が自動縮小された場合も比率を保ちます。
- イベントの選択肢は、広げた表示枠にハイライト・影・発光も追従します。
- マップの凡例は併記中だけ行間と紙の高さを広げ、単独表示では元の配置に戻します。
- 長いイベント本文は枠内をスクロールできます。背景色はゲーム本来のまま、選択肢は画面内に残します。
- 本体の言語設定を変更すると、その言語をMODの「言語1」に反映します。併記中なら併記を続けます。言語2と同じ言語を選ぶと、言語1と言語2を入れ替えます。
- Cでは本体の保存済み言語設定を変更しません。

対応言語は英語、日本語、中国語簡体字・繁体字、ドイツ語、スペイン語（中南米・スペイン）、フランス語、インドネシア語、イタリア語、韓国語、ポーランド語、ポルトガル語（ブラジル）、ロシア語、タイ語、トルコ語です。

MODの設定ファイルは `~/Library/Application Support/SlayTheSpire2/mod_configs/BilingualSpire.json` に保存されます。
表示モードが未保存の場合は言語1で起動します。Cで単独表示や併記を選んだ場合は、次回もそのモードを復元します。

## ソースからビルド

開発する場合や自分でビルドする場合の手順です。通常の導入は上のZIPを使ってください。
必要なものは、SteamでインストールしたMac版Slay the Spire 2と.NET 9 SDKです。
検証に使用したSDKは9.0.321で、使用するバージョンは [global.json](global.json) に指定しています。
このMODはDLLとJSONで動作し、BaseLib・PCK・MegaDotエディターは不要です。

ゲームを終了してから実行してください。

```sh
git clone https://github.com/guppi-tw/sts2-bilingual-spire.git
cd sts2-bilingual-spire
./scripts/deploy.sh -c Release
./scripts/launch.sh
```

`deploy.sh` はビルド後、Steamの標準ライブラリにある次のフォルダへMODを配置します。

```text
~/Library/Application Support/Steam/steamapps/common/Slay the Spire 2/
  SlayTheSpire2.app/Contents/MacOS/mods/BilingualSpire/
```

ゲーム内の「設定 → MOD設定」で「Bilingual Spire」を有効にしてください。
無効にする場合も同じ画面からオフにして再起動します。
`launch.sh` はSteam経由でゲームを起動します。

別のSteamライブラリを使う場合は、プロジェクト直下にGit管理対象外の `local.props` を作ります。

```xml
<Project>
  <PropertyGroup>
    <Sts2Path>/path/to/steamapps/common/Slay the Spire 2</Sts2Path>
  </PropertyGroup>
</Project>
```

Intel Mac用の参照先は `Sts2Architecture` を `x86_64` にして指定できますが、動作確認はApple Siliconのみです。
付属の起動・テストスクリプトはmacOSの標準Steam配置を対象とします。
ゲームのDLLはインストール先から参照し、このリポジトリには含めません。

読み込みを確認するには次を実行します。

```sh
./scripts/check-log.sh
```

## 動作確認

2026-11-15にゲームv0.113.0で、次を実ゲーム内のテストと画面画像で確認しました。

- 初回起動時の言語1表示、Zによる一時翻訳と復帰、本体の保存済み言語を変更しないこと
- 6種類のカード、強化後の数値、非公開表示、メニュー、C/G、16言語の切り替え
- 英日・仏韓の併記、新しく表示された文への適用、重複の防止、単独表示への復帰
- レリック報酬・長いレリック名・関連効果のツールチップ見出しの横並び、文字サイズと枠への収まり
- 自己啓発本、Waterlogged Scriptorium、ドール・ルーム、ネオーの英日表示
- イベント本文末尾までのスクロール、選択肢の位置、ドール・ルームの選択後のページ更新、ネオーの3段階の会話
- ネオーの「小さなカプセル」選択から追加レリック取得、3モードでの「進む」の表示、マップへの移動、完了済みイベントの再開
- 凡例の見出しと6項目の収まり、16言語をそれぞれ言語1・言語2にした表示、仏韓の併記、Cでの配置復元とフォーカス操作
- 凡例・カード・イベント本文の訳文サイズ、カードの自動縮小後の比率、段落ごとの装飾、イベント本文の背景、選択肢のホバー時のハイライトと単独表示への復帰
- メニュー・プロフィール欄の16言語との併記、文字サイズとクリック範囲、単独表示への復元
- カードへのマウスホバーと解除、画面左右での対訳の収まり、長文のホイール操作、アップグレード時の数値、ホバー中のモード・言語変更、ロック中のカードの非表示
- 本体の言語設定との連動、段落ごとの対訳、文字装飾の保持、段落数が異なる場合の全文併記
- Zの押下・長押し・解除、設定ファイルを更新しないこと、文字入力中の無効化、フォーカス喪失時の復元、C/G・言語設定との併用、押したまま終了した後の再起動
- Z・C・Gと本体の標準キー割り当ての重複がないこと、Command・Control・Option・Shiftとの同時押しと各キーを離す順序、1行・複数行の文字入力中の無効化
- 3モードの再起動後の復元と、復元後のC操作・保存。本体の初期言語を毎回フランス語にして、英語・日本語への復元漏れを検出

全イベント・全言語ペア・戦闘を含む通しプレイの網羅確認はしていません。
カード内の長い本文は縮小されるため、ホバー時の大きな対訳で読めます。MOD適用中の表示やイベント見出しなど、一部の文字はまだ小さくなる場合があります。Cで単独表示にも戻せます。
実測した文字サイズと対応状況は[読みやすさの調査](docs/readability-audit.md)に記録しています。
画像内の文字、翻訳キーがない固定文、他MODの独自表示には対応しない場合があります。
会話・説明文・選択肢を優先し、キャラクターなどの固有名詞の併記は必須としていません。

ゲーム更新後は再ビルドと動作テストが必要です。

## テストの実行

ゲームを終了してから実行してください。

```sh
python3 scripts/smoke-test.py
```

Debugビルドを配置し、Steam接続を無効にした実ゲームをヘッドレスで起動します。
一時的な非Steam用プロフィールでテストし、既存の非Steam用データは終了時に復元します。
Steam用セーブが変わっていないことと、非Steam用データの復元をSHA-256で検証します。
MODの設定ファイルもテストごとの一時フォルダに分離します。

イベント検証では保存しないテスト用ランを作り、画面表示と選択肢の操作を検査します。
ネオーはレリック報酬を受け取る操作からマップ表示まで検査し、凡例の文字と表示枠、完了済みの状態からの再開も確認します。
Zを押したまま終了するテストの後、ゲームを3回再起動し、各モードの復元とCによる次のモードへの変更・保存を検査します。
全プロセスの終了コードと成功マーカーに加え、ゲームの `[ERROR]` ログとC#例外の有無も検査します。

画面画像も取得する場合は次を使います。

```sh
python3 scripts/smoke-test.py --visual
```

表示とイベントのテストではゲームウィンドウを開き、各テストの終了後に閉じます。再起動テストはヘッドレスです。
ログと画像は `.artifacts/` に保存します。既存データの退避先は `.artifacts/isolated-test-*/original-default` です。
強制終了などで退避データが残っている場合は、復元するまで `.artifacts/` を削除しないでください。

テスト後は通常用のReleaseビルドを配置してください。Releaseビルドにはテストコードを含みません。

```sh
./scripts/deploy.sh -c Release
```

## コードの構成

| 場所 | 役割 |
| --- | --- |
| `LanguageSwitcher.cs` | Zの一時翻訳、C/G、表示モード、本体の言語設定との連動 |
| `Localization/` | 翻訳キーと表示文の追跡、段落ごとの対訳、フォント調整 |
| `Patches/` | ゲームへのHarmonyパッチ、カード・イベントの表示更新 |
| `Settings/` | 言語ペアと表示モードの保存 |
| `UI/` | 言語選択欄と通知 |
| `Development/` | 実ゲーム内で動くDebug専用テスト |
| `scripts/` | ビルド・配置・起動・テスト |

ゲームの翻訳キーと変数から表示文を再生成します。カードは本体の表示更新処理も呼び、数値やキーワードの構成を維持します。
対象を特定できない文はそのまま残します。
